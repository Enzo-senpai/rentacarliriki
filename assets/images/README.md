# Images Folder

This folder contains all the images used in the Rent a Car Liriki website.

## Required Images

### Car Images

- `audi-a3.jpg` - Audi A3 car image
- `bmw-x3.jpg` - BMW X3 car image
- `mercedes-c.jpg` - Mercedes C-Class car image

### Recommended Image Specifications

- **Format**: JPG or PNG
- **Size**: 800x600 pixels minimum
- **Quality**: High quality, professional car photos
- **Style**: Clean, modern car photography with good lighting

### How to Add Images

1. Place your car images in this folder
2. Make sure the filenames match exactly with what's referenced in the HTML
3. Optimize images for web (compress to reduce file size while maintaining quality)

### Alternative

If you don't have specific car images, you can:

1. Use stock photos from websites like Unsplash, Pexels, or Pixabay
2. Use placeholder images temporarily
3. Contact us for professional car photography services

## Image Optimization Tips

- Use WebP format for better compression (with JPG fallback)
- Keep file sizes under 500KB for faster loading
- Use descriptive alt text for accessibility
- Consider lazy loading for better performance
